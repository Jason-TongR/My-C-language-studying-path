# C Programming Coursework

Coursework and practice programs written in C for **Introduction of Computer Science (Henan)** at **GTIIT**. This repository documents my progress from fundamental programming constructs to arrays, functions, recursion, and algorithm analysis.

> An archive of course work; it is not actively maintained.

## What This Repository Demonstrates

- Writing small, standalone C programs with console input and output
- Applying variables, arithmetic, conditionals, loops, and functions to problem solving
- Processing characters and sequences, including command-line arguments and standard input
- Working with arrays and two-dimensional matrices
- Implementing recursive algorithms and examining search behavior
- Simulating randomized games and comparing strategies through repeated trials

Each exercise is provided as an individual `.c` source file. There is no shared build system; compile and run a selected program with a C compiler, for example:

```sh
gcc -std=c11 -Wall -Wextra path/to/program.c -o program
./program
```

Some programs expect command-line arguments or input from standard input; check the source file for its input format.
